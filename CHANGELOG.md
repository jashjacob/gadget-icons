# Changelog

- Added external hard drive, SD card, and wireless charging stand icons. The collection now includes 47 icons.
- Redrew the robot vacuum with a dock and added a grille to the smart speaker. Both keep their existing names.

- Added search aliases and shareable icon links that preserve size and stroke.
- Added product details, category navigation, and storage comparison examples to the gallery.
- Updated npm metadata and the README, including installation examples and the complete icon index.
